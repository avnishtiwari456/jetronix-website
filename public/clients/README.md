# Customer logos

Drop a logo file here and name it in `customers` in `src/data.ts`:

    { name: "Cipla", logo: "cipla.svg" }

Until a `logo` is named, the strip on the home page shows the customer's
name as text instead, so the section works either way.

What works best:
- SVG, or PNG with a transparent background
- The mark trimmed to its own edges, no surrounding whitespace
- About 160px wide is plenty; the strip draws them 32px tall

These are other companies' trademarks. Use the file each customer supplies
for partner or vendor use, or ask them for written permission first.
